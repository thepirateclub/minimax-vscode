# Goal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The user sets a goal with limits, the agent counts the spend of every request and stops by itself when the budget is over.

**Architecture:** The host owns the goal. The user sets it in a widget over the feed, the model reads it from the prompt and changes its status through the tool `update_goal`. The agent sends the spend of every request as the new event `usage`, the host adds it to the goal and checks the limits; when a limit is reached the agent stops with the new reason `goal_limit` and the status of the goal stays `active`, the user raises the limit and the work continues.

**Tech Stack:** TypeScript, VS Code extension API, React 18 in the webview, vitest, esbuild.

```ts
import type { GoalState, ToolStateUpdate } from '../agent/state';
import type { ToolEntry } from './types';

const STATUSES = ['complete', 'blocked'];

// The goal as the model reads it.
export function formatGoal(goal: GoalState): string {
  const lines: string[] = ['Goal: ' + goal.objective];
  const limits: string[] = [];
  if (goal.tokenBudget !== undefined) {
    limits.push(goal.tokenBudget + ' tokens');
  }
  if (goal.requestLimit !== undefined) {
    limits.push(goal.requestLimit + ' requests');
  }
  if (goal.secondsLimit !== undefined) {
    limits.push(goal.secondsLimit + ' seconds');
  }
  if (limits.length > 0) {
    lines.push('Budget: ' + limits.join(', '));
  }
  lines.push(
    'Used: ' +
      goal.used.tokens +
      ' tokens, ' +
      goal.used.requests +
      ' requests, ' +
      Math.round(goal.used.seconds) +
      ' seconds'
  );
  if (goal.status !== 'active') {
    lines.push('Status: ' + goal.status);
  }
  return lines.join('\n');
}

export function createGoalTools(): ToolEntry[] {
  const getGoal: ToolEntry = {
    name: 'get_goal',
    description:
      'Read the goal of the session with its limits and the spend of the budget. The goal is also in the context of every turn, use this tool when you need the exact numbers.',
    approval: 'never',
    sideEffect: false,
    inputSchema: { type: 'object', properties: {} },
    async execute(_input, ctx) {
      const goal = ctx.sessionState?.goal;
      if (!goal) {
        return { content: 'There is no goal for this session.' };
      }
      return { content: formatGoal(goal) };
    }
  };

  const updateGoal: ToolEntry = {
    name: 'update_goal',
    description:
      'Mark the goal of the session as complete or blocked. Use it when the work of the goal is done or when it cannot be done. You cannot change the limits of the goal, the user does that.',
    approval: 'never',
    sideEffect: false,
    inputSchema: {
      type: 'object',
      properties: {
        status: {
          type: 'string',
          enum: ['complete', 'blocked'],
          description: 'The state of the goal.'
        },
        note: {
          type: 'string',
          description: 'A short reason, one line.'
        }
      },
      required: ['status']
    },
    async execute(input, ctx) {
      if (!ctx.sessionState?.goal) {
        return {
          content: 'There is no goal for this session, there is nothing to update.',
          isError: true
        };
      }
      const status = String(input['status'] ?? '');
      if (!STATUSES.includes(status)) {
        return {
          content:
            'The status of the goal is "complete" or "blocked", not "' + status + '".',
          isError: true
        };
      }
      // The limits belong to the user. A tool that changes them would let
      // the model walk around the stop of the budget.
      for (const key of ['tokenBudget', 'requestLimit', 'secondsLimit']) {
        if (input[key] !== undefined) {
          return {
            content:
              'The limits of the goal belong to the user, the model cannot change them.',
            isError: true
          };
        }
      }
      const note = typeof input['note'] === 'string' ? input['note'].trim() : '';
      const state: ToolStateUpdate = {
        kind: 'goal',
        status: status as 'complete' | 'blocked',
        note: note.length > 0 ? note : undefined
      };
      return {
        content:
          'The goal is marked as ' +
          status +
          (note.length > 0 ? ': ' + note : '.') +
          ' The status of the goal is set by the model, the limits stay with the user.',
        state
      };
    }
  };

  return [getGoal, updateGoal];
}
```

The budget is checked in two places.

Inside the stream, before every event. The limit of the time can run out in
the middle of a long answer, the stream stops there and the turn ends with
the reason `goal_limit`. The text that was already streamed stays in the
panel, the tools of the request do not run, and the limits of the tokens and
of the requests are counted after the request, so only the limit of the time
can trip here.

After the request, before the tools run. The request that just went out can
be the one that broke the budget, then the tools do not run and the model
gets no more work:

```ts
      if (this.options.budget && !this.options.budget()) {
        this.options.onEvent({ type: 'done', stopReason: 'goal_limit', usage });
        return { messages, stopReason: 'goal_limit', usage, requestIndex };
      }
```

The request is closed on the wire when the stream is abandoned. The agent can
leave the stream in the middle of an answer, the budget of the goal ran out or
the user stopped the turn. The client then cancels the reader of the body of
the response in `src/api/client.ts`, the server stops the generation of that
answer and the socket of the extension host is closed. Without the cancel the
server keeps generating the answer to the end and the socket stays open, the
generation is paid for nothing. The spend of an interrupted request does not
reach the counter of the goal either way, the server reports the usage only in
`message_stop`, which an interrupted request never gets. A stream that
already ended is left alone, and the error of a broken stream still reaches
the caller. The behaviour is covered by `test/unit/client.test.ts`.

An answer that ends the turn without tools stays an answer, the notice about
the budget comes when the agent would have done more work. The check does not
stand at the top of the loop: nothing happens between the end of the tools
and the next iteration that could change the budget, and a check there would
stop the agent before the first request, while the test of the task expects
one request to go out.

```ts
export function budgetOver(goal: GoalState, usage: GoalUsage): boolean {
  if (goal.tokenBudget !== undefined && usage.tokens >= goal.tokenBudget) {
```

```tsx
import { useEffect, useState } from 'react';
import type { GoalState } from '../../../agent/state';
import { STRINGS } from '../strings';

export interface GoalValues {
  objective: string;
  tokenBudget?: number;
  requestLimit?: number;
  secondsLimit?: number;
}

// The text of the form of the limits.
export interface GoalForm {
  objective: string;
  tokens: string;
  requests: string;
  minutes: string;
}

// A big count of tokens is written in thousands, the panel is narrow.
export function formatTokens(value: number): string {
  if (value < 1000) {
    return String(value);
  }
  const thousands = value / 1000;
  const text = thousands >= 100 ? String(Math.round(thousands)) : thousands.toFixed(1);
  return text.replace(/\.0$/, '') + 'k';
}

// The time of the goal is written in minutes and seconds.
export function formatDuration(seconds: number): string {
  const total = Math.max(0, Math.round(seconds));
  const minutes = Math.floor(total / 60);
  const rest = total % 60;
  if (minutes === 0) {
    return rest + 's';
  }
  if (rest === 0) {
    return minutes + 'm';
  }
  return minutes + 'm ' + rest + 's';
}

// The form is filled from the goal when it opens.
export function goalFormValues(goal: GoalState | undefined): GoalForm {
  return {
    objective: goal?.objective ?? '',
    tokens: goal?.tokenBudget === undefined ? '' : String(goal.tokenBudget),
    requests: goal?.requestLimit === undefined ? '' : String(goal.requestLimit),
    minutes:
      goal?.secondsLimit === undefined ? '' : String(Math.round(goal.secondsLimit / 60))
  };
}

// An empty field means "without a limit". A field with a wrong number is
// an error, it never takes the limit away.
function parseLimit(text: string): { ok: true; value?: number } | { ok: false } {
  const value = text.trim();
  if (value.length === 0) {
    return { ok: true, value: undefined };
  }
  const parsed = Number(value);
  if (!Number.isFinite(parsed) || parsed <= 0) {
    return { ok: false };
  }
  return { ok: true, value: Math.floor(parsed) };
}

export function parseGoalForm(form: GoalForm): {
  values?: GoalValues;
  error?: 'empty' | 'badLimit';
} {
  if (form.objective.trim().length === 0) {
    return { error: 'empty' };
  }
  const tokens = parseLimit(form.tokens);
  const requests = parseLimit(form.requests);
  const minutes = parseLimit(form.minutes);
  if (!tokens.ok || !requests.ok || !minutes.ok) {
    return { error: 'badLimit' };
  }
  return {
    values: {
      objective: form.objective.trim(),
      tokenBudget: tokens.value,
      requestLimit: requests.value,
      secondsLimit: minutes.value === undefined ? undefined : minutes.value * 60
    }
  };
}

// The host confirms the goal, the values of the form and the goal of the
// session have to be the same.
export function goalMatches(values: GoalValues, goal: GoalState | undefined): boolean {
  if (!goal) {
    return false;
  }
  return (
    goal.objective === values.objective &&
    goal.tokenBudget === values.tokenBudget &&
    goal.requestLimit === values.requestLimit &&
    goal.secondsLimit === values.secondsLimit
  );
}

  const [pending, setPending] = useState<GoalValues | undefined>(undefined);

  // values of the moment of the mount shows empty fields while the limits

  // The form closes only when the host confirms the goal. A refused save
  // keeps the text of the user, otherwise the work of the user is lost.
  useEffect(() => {
    if (pending && goalMatches(pending, goal)) {
      setPending(undefined);
      setEditing(false);
    }
  }, [goal, pending]);

  const submit = (): void => {
    const parsed = parseGoalForm(form);
    if (!parsed.values) {
      setError(parsed.error === 'empty' ? STRINGS.goalEmpty : STRINGS.goalBadLimit);
      return;
    }
    setError('');
    setPending(parsed.values);
    onSet(parsed.values);
  };

  // Without a goal the widget still stands above the feed, otherwise the
  // user has no way to set a goal at all.
  if (!goal && !editing) {
    return (
      <div className="goal-bar">
        <button className="goal-button" onClick={openEditor}>
          {STRINGS.goalSet}
        </button>
      </div>
    );
  }

  return (
    <div className="goal-bar">
      {editing ? (
        <div className="goal-form">
          <input
            className="goal-input"
            type="text"
            value={form.objective}
            placeholder={STRINGS.goalObjective}
            aria-label={STRINGS.goalObjective}
            onChange={(event) => setForm({ ...form, objective: event.target.value })}
          />
          <input
            className="goal-input"
            type="text"
            value={form.tokens}
            placeholder={STRINGS.goalTokenLimit}
            aria-label={STRINGS.goalTokenLimit}
            onChange={(event) => setForm({ ...form, tokens: event.target.value })}
          />
          <input
            className="goal-input"
            type="text"
            value={form.requests}
            placeholder={STRINGS.goalRequestLimit}
            aria-label={STRINGS.goalRequestLimit}
            onChange={(event) => setForm({ ...form, requests: event.target.value })}
          />
          <input
            className="goal-input"
            type="text"
            value={form.minutes}
            placeholder={STRINGS.goalMinuteLimit}
            aria-label={STRINGS.goalMinuteLimit}
            onChange={(event) => setForm({ ...form, minutes: event.target.value })}
          />
          <button className="goal-button" onClick={submit}>
            {STRINGS.goalSave}
          </button>
          <button className="goal-button" onClick={() => setEditing(false)}>
            {STRINGS.goalCancel}
          </button>
          {error.length > 0 ? <span className="goal-error">{error}</span> : null}
        </div>
      ) : (
        <div className="goal-row">
          <span className="goal-objective">{goal?.objective}</span>
          <span className="goal-spend">
            {formatTokens(goal?.used.tokens ?? 0)}/
            {goal && goal.tokenBudget !== undefined ? formatTokens(goal.tokenBudget) : '∞'} tokens
          </span>
          <span className="goal-spend">
            {goal?.used.requests ?? 0}/
            {goal && goal.requestLimit !== undefined ? goal.requestLimit : '∞'} requests
          </span>
          <span className="goal-spend">
            {formatDuration(goal?.used.seconds ?? 0)}/
            {goal && goal.secondsLimit !== undefined ? formatDuration(goal.secondsLimit) : '∞'}
          </span>
          {goal && goal.status !== 'active' ? (
            <span className="goal-status">{goal.status}</span>
          ) : null}
          <button className="goal-button" onClick={openEditor}>
            {STRINGS.goalEdit}
          </button>
          <button className="goal-button" onClick={onClear}>
            {STRINGS.goalClear}
          </button>
        </div>
      )}
    </div>
  );
}
```
