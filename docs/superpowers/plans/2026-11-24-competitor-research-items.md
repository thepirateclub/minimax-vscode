# План: пункты из сравнения с другими агентами

Источник: `reports/Сравнение агентов для VS Code.md`, короткий список. Пользователь взял все девять пунктов. Порядок по силе доказательства: сначала то, у чего есть замер эффекта на качество кода.

Каждый пункт начинается с падающего теста, заканчивается зелёными `npm run typecheck` и `npm test`, правилом в AGENTS.md и подъёмом версии.

1. **Диагностика после правки.** После успешных `write_file` и `edit_file` хост читает ошибки и предупреждения файла из языкового сервера (`vscode.languages.getDiagnostics`) и дописывает их в результат инструмента. Модель видит, что сломала, в том же ходе. Слой инструментов не знает про `vscode`: зависимость `diagnostics` передаётся в `createAllTools`. Замер SWE-agent: 18,0% против 15,0% с проверкой правки.
2. **Мягкое совпадение в `edit_file`.** Точное совпадение остаётся первым. Если его нет, правка ищет фрагмент без учёта пробелов в конце строк и отступов, и применяет его, только если он единственный. При промахе ошибка называет ближайший похожий фрагмент с номерами строк. Превью правки (`buildPreview`) повторяет ту же арифметику. Aider: без нестрогого сопоставления ошибок правки в 9 раз больше.
3. **Очистка старых результатов инструментов.** Перед запросом длинные результаты инструментов старше последних N ходов заменяются короткой заглушкой с именем инструмента и объектом. Пары вызов и результат не рвутся. Кэша промпта у MiniMax нет, поэтому экономия прямая.
4. **Verifier запускает тесты.** Роль `verifier` под-агента получает в промпте правило: найти и запустить существующие тесты проекта и, если нужно, написать воспроизводящий тест, прежде чем подтвердить работу. Agentless: 27% → 32%.
5. **Откат файлов вместе с откатом сообщения.** Откат к запросу возвращает файлы, которые агент изменил после него, из хранилища бэкапов (чекпоинт хода).
6. **Разрешения с областью.** Вместо одного `autoApprove`: разрешить команду по префиксу, запись в папку, инструмент на сессию. Правила живут на уровне пользователя.
7. **Карта репозитория.** Компактная карта символов проекта (файлы и их экспортируемые объявления) в системном промпте, бюджет около 1K токенов, из уже существующего индекса.
8. **Problems агенту.** Упоминание `@problems` в поле ввода и кнопка в панели Problems прикладывают ошибки рабочей области к запросу.
9. **Пара планировщик и исполнитель.** Опция: план строит M3, правки делает M3.1-Flash. Включается только после локального замера на задачах проекта.
