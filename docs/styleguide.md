# Styleguide панели MiniMax

Стандарт отображения вебвью-панели. Панель живёт внутри VS Code и должна выглядеть как часть редактора, а не как отдельный сайт: цвета берутся из темы хоста, акцент один, всё вторичное приглушено.

Источник правды: токены в `src/ui/webview/styles.css` (блок `body`). Соблюдение проверяет тест `test/unit/styleguide.test.ts`. Стенд для глаза: `npm run preview` (http://localhost:5199, параметры `?theme=light`, `?busy=1`, `?collapse=1`, `?empty=1`, `?nokey=1`).

## Принципы

1. **Ответ главный.** Текст модели идёт полным цветом. Карточки действий, размышление, служебные подписи приглушены (`--muted`) и получают полный цвет только при наведении.
2. **Один акцент.** `--accent` означает «интерактивно» или «активно»: ссылка, фокус, активная вкладка, выбранный пункт, прогресс, приглашение `$`. Заголовки, маркеры списков и метки языка акцентом не красятся.
3. **Цвет несёт смысл.** Зелёный значит успех, красный значит ошибку, жёлтый значит предупреждение. Декоративного цвета нет.
4. **Тема хоста.** Каждый цвет это `var(--vscode-*, запасной)` или токен поверх него. Голый hex допустим только в палитрах `--tok-*` и `--diff-*`, где тема редактора не даёт нужного контраста.
5. **Иконки, а не глифы.** Кнопка без подписи рисуется SVG из `icons.tsx`. Текстовые `+`, `×`, `▸`, `▾` не используются. Исключение одно: крестик чипа внутри `contenteditable`, там SVG ломает каретку.

## Токены

Токены объявлены на `body`, а не на `:root`: размер шрифта панели меняется через `--mm-font-base` на `body`, и вычисляемые от него токены должны считаться там же.

### Типографика

| Токен | Значение | Где |
|---|---|---|
| `--fs-xs` | `base * 0.77` | время действия, метки `stderr`, `selection`, бейджи, кнопка `Copy` |
| `--fs-sm` | `base * 0.85` | карточки действий, моноширинный вывод, селекторы, вторичный текст |
| `--fs-md` | `base * 0.92` | кнопки, поля ввода, пункты меню, пузырь пользователя |
| `--fs-base` | `base` | текст ответа |

Заголовки markdown задаются в `em` от текста ответа. Начертания два: 400 и 600. Межстрочный интервал: `--lh` (1.5) для текста, `--lh-tight` (1.3) для заголовков.

### Отступы

Шкала в пикселях: `2, 4, 6, 8, 12, 16, 24, 32`, плюс `1px` для тонкой подгонки. Горизонтальное поле панели 12px: шапка, лента, композер и настройки начинаются на одной вертикали. Между сообщениями 12px, подряд идущие карточки действий собираются в группу с шагом 4px.

### Размеры

| Токен | Значение | Где |
|---|---|---|
| `--control-h` | 22px | все квадратные иконочные кнопки и селекторы под полем ввода |
| `--icon` | 14px | все иконки интерфейса |
| `--dot` | 8px | точки состояния агента и действия |

### Радиусы

| Токен | Значение | Где |
|---|---|---|
| `--radius-sm` | 4px | кнопки, чипы, поля, блоки внутри карточек, инлайновый код |
| `--radius` | 6px | контейнеры: пузырь, блок кода, поле ввода, меню, карточка подтверждения |
| — | 999px | плавающие пилюли: `Show earlier messages`, `Jump to the latest` |
| — | 50% | точки |

Отметка ошибки слева (`border-left`) всегда без скругления.

### Цвета

| Токен | Основа | Смысл |
|---|---|---|
| `--fg` | `--vscode-foreground` | основной текст |
| `--muted` | `--vscode-descriptionForeground` | вторичный текст, иконки в покое |
| `--border` | `--vscode-widget-border` | все рамки и разделители |
| `--accent` | `--vscode-textLink-foreground` | интерактив и активное состояние |
| `--ok` | `--vscode-testing-iconPassed` | успех |
| `--err` | `--vscode-testing-iconFailed` | ошибка: точка, черта, строка терминала, кнопка остановки |
| `--warn` | `--vscode-inputValidation-warningBorder` | предупреждение |
| `--hover` | `--vscode-toolbar-hoverBackground` | подложка иконочной кнопки при наведении |
| `--row-hover` | `--vscode-list-hoverBackground` | подложка строки списка при наведении |
| `--surface` | `--vscode-editorWidget-background` | шапки блоков, приподнятые поверхности |
| `--code-bg` | `--vscode-textCodeBlock-background` | код и вывод инструментов |
| `--shadow` | — | единственная тень, только у всплывающих слоёв |

## Компоненты

- **Иконочная кнопка** (`.icon-button`, `.composer-attach`, `.composer-send`, `.tool-copy`): квадрат `--control-h`, без рамки, прозрачная, иконка `--muted`, при наведении подложка `--hover` и цвет `--fg`.
- **Текстовая кнопка**: в группе одна основная (`button`), остальные `secondary`. В карточке подтверждения основная только `Allow`.
- **Шеврон раскрытия**: одна иконка `IconCaret`, свёрнутое состояние поворачивает её на -90°. Используется в карточке действия, размышлении и блоке кода.
- **Точка состояния**: `--dot`, цвета `--ok`, `--err`, `--muted`. Мигает только идущий процесс.
- **Всплывающий слой** (меню селектора, история чатов, подсказки `@`): рамка `--border`, радиус `--radius`, тень `--shadow`, пункт меню `--fs-md` или `--fs-sm`, подложка пункта при наведении `--row-hover`.
- **Блок с моноширинным текстом** (код, диф, вывод, аргументы действия, чтение файла, размышление): всегда в рамке `--border`, заливка одна его не держит: в Light Modern подложка кода совпадает с фоном боковой панели. Радиус `--radius-sm` внутри карточки и `--radius` в ответе, кегль `--fs-sm`, высота не больше 300px с прокруткой.
- **Пузырь пользователя**: спокойная подложка `--vscode-textBlockQuote-background` и основной цвет текста. Заливка цветом кнопки спорила с ответом.
- **Шапка**: одинаковая высота на обеих вкладках, график расхода виден и в настройках, иначе панель прыгает при переключении.
- **Прокрутка**: тонкая полоса 8px, бегунок с отступом от края, дорожка прозрачная.
- **Фокус**: у кнопок `:focus-visible` даёт рамку `--vscode-focusBorder`, мышиный клик рамку не рисует.

## Чего не делать

- Новый кегль, радиус, тень или отступ вне шкалы: сначала токен и строка в этом файле.
- Блок, который отделён от фона только заливкой: в части тем она совпадает с фоном панели.
- `opacity` на цветной заливке поверх фона с рисунком: сквозь неё просвечивает рисунок. Нужен смешанный цвет (`color-mix`).
- Разные оттенки красного для одной ошибки.
- Класс в разметке без правила в стилях.
