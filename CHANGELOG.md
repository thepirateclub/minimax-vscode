# История изменений

Все значимые изменения расширения MiniMax Agent. Формат версии следует semver, даты в формате ГГГГ-ММ-ДД.

## Как шла разработка

Проект написан агентом, а не человеком за клавиатурой. Всё, что ниже, разложено по версиям, но сама разработка шла циклом: агент читал проект, звал инструменты, правил файлы и запускал команды, а решение принимал по подтверждению пользователя.

Правила работы зафиксированы в [AGENTS.md](AGENTS.md): что менять можно, что нельзя, как выглядит панель и почему так. Каждое решение в проекте записано туда же вместе с причиной, поэтому следующий шаг делается по правилу, а не по памяти модели.

Ключевые черты процесса:

- Агентный цикл живёт только в extension host, webview не ходит в сеть и не хранит ключ.
- Каждая запись на диск и каждый запуск команды спрашивают подтверждение, правило не обходится.
- Каждое изменение поведения закрывается тестом, тест проверяет смысл, а не деталь реализации.
- Файл длиннее 400 строк делится по смыслу, а не переименовывается.
- Клиент MiniMax написан вручную на `fetch` с собственным разбором SSE, официальный SDK не используется.
- Коммиты и правила проекта на русском, тексты интерфейса и всё, что уходит в модель, на английском.

Первые версии закрывали каркас расширения и агентный цикл, дальше шли инструменты и возможности панели, в конце появились навыки, MCP, веб-поиск и работа с картинками. Полные правила и решения описаны в [AGENTS.md](AGENTS.md) и [CONTRIBUTING.md](CONTRIBUTING.md).

## 0.43.0 - 2026-11-25

### Добавлено

- Команды редактора для выделенного кода (контекстное меню и палитра): `Explain Selection` сразу спрашивает объяснение в чате, `Annotate Selection for Chat` (Ctrl+Alt+N) прикрепляет кусок с заметкой, аннотаций может быть несколько, `Improve Selection` улучшает участок по промпту настройки `minimax.improvePrompt` (пусто: встроенный промпт), `Add Comments to Selection` пишет комментарии в код. ## 0.42.5 - 2026-11-25

### Безопасность

- `web_fetch` больше не читает локальную сеть: `localhost`, частные адреса, роутер и служба метаданных облака отвергаются, имя проверяется после DNS, редирект на локальный адрес не выполняется.
- `minimax.semanticSearch` и `minimax.enableWebSearch` читаются только из настроек пользователя: репозиторий не включит отправку кода и запросов на сервер своим `.vscode/settings.json`.

### Исправлено

- Версия в `package-lock.json` совпадает с версией расширения.
- README называет все инструменты агента, правила проекта описывают концы строк LF.
- Публикация в Marketplace идёт через токен `VSCE_PAT`: Trusted Publishing пока не принимает immutable subject GitHub.

## 0.42.4 - 2026-11-25

### Исправлено

- Картинка, вставленная в поле ввода, больше не встаёт внутрь текста. Хост сохраняет её в `.minimax/agent/attachments/`, в поле стоит чип с именем файла, над полем миниатюра, удаление чипа убирает миниатюру. Модель смотрит картинку через `read_image`.
- Текст вставляется в поле без разметки страницы, откуда он скопирован.
- Ссылка `@` на картинку больше не прикладывает байты файла как текст, а называет путь для `read_image`.
